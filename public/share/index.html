共享你的 GitHub Token / Share Your GitHub Token

通过 GitHub 官方授权（Device Flow）一键把 Token 加入共享池，用于 Home Assistant Marketplace 的安装加速。 One-click share via GitHub's official Device Flow. Your token powers the Home Assistant Marketplace acceleration.

🔒 数据获取与使用声明 / Data Disclosure

  • 获取什么 / What we receive：仅 GitHub 授权产生的 Token（零权限 / zero scope，无法读取你的任何仓库、无法写入、无法读取私人数据）以及你的 GitHub 账号公开用户名（login）。 Only the token GitHub issues to this site (with zero scope — it cannot read or write any of your repositories or data) and your public GitHub username.
  • 如何使用 / How it is used：Token 仅存于本站服务端（腾讯 EdgeOne 边缘节点），用于在他人通过本站安装 Marketplace 资源时消耗其每小时 API 额度，让你贡献的额度帮助其他用户。 Stored server-side only (Tencent EdgeOne edge nodes) and used solely to serve other users' Marketplace requests within GitHub's hourly API quota.
  • 不会做什么 / What we never do：不在页面显示 Token 明文；不用于任何其他服务；不与第三方共享；不记录与你身份相关的访问日志。 Never displayed in full on any page, never used for anything else, never shared with third parties, no identity-linked access logs.
  • 随时退出 / Revoke anytime：前往 GitHub → Settings → Security → Applications 取消授权即可，你的 Token 会立即失效，我们会在定期验活时自动将其移出共享池。 Revoke at GitHub → Settings → Security → Applications. The token dies instantly and is pruned from the pool automatically during periodic revalidation.
