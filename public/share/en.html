Add your token to the shared pool in one click via GitHub's official Device Flow authorization.
It powers the Home Assistant Marketplace acceleration for everyone.

🔒 Data Disclosure

  • What we receive: only the token GitHub issues to this site through your authorization (zero scope — it cannot read or write any of your repositories or data), plus your public GitHub username (login).
  • How it is used: the token is stored server-side only (Tencent EdgeOne edge nodes) and used solely to serve other users' Marketplace requests within GitHub's hourly API quota.
  • What we never do: never display the full token on any page; never use it for anything else; never share it with third parties; no identity-linked access logs.
  • Revoke anytime: visit GitHub → Settings → Security → Applications and revoke this site. The token dies instantly and is pruned from the pool automatically during periodic revalidation.
